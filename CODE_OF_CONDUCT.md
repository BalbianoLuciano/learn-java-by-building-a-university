# Código de conducta

Este proyecto adopta el **Contributor Covenant, versión 2.1**:
https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/

## En resumen

Nos comprometemos a que participar en este proyecto sea una experiencia libre de acoso
para todas las personas, sin importar edad, cuerpo, discapacidad, etnia, identidad o
expresión de género, nivel de experiencia, educación, nivel socioeconómico, nacionalidad,
apariencia, religión u orientación sexual.

Esperamos:

- Trato respetuoso y amable, especialmente con quien está aprendiendo.
- Críticas al código o al contenido, nunca a las personas.
- Aceptar con apertura las correcciones y reconocer los errores.

No se aceptan: lenguaje o imágenes sexualizadas, insultos, ataques personales, acoso
público o privado, ni publicar datos personales de otras personas sin permiso.

## Cómo reportar

Escribí a **balbiano06@gmail.com** describiendo la situación. Los reportes se tratan con
confidencialidad. Las consecuencias y el proceso de aplicación siguen las pautas del
Contributor Covenant 2.1.
