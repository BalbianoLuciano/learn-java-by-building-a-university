# ADR 0009 · Política de idiomas

- **Estado:** aceptada
- **Fecha:** 2026-10-01

## Contexto

El público es hispanohablante, pero el código debe seguir buenas prácticas y ser legible para cualquier colaborador. La cátedra usa identificadores en español.

## Decisión

- Código, API, nombres técnicos, commits y comentarios: **inglés**.
- Textos de interfaz y contenido: **español** (voseo), en archivos de traducción.
- Java que escribe el alumno (dominio de los desafíos): **español** (`FacultadRegional`).
- Documentación del proyecto: **español**.

## Consecuencias

- Sumar inglés al contenido no requiere tocar código.
- Las claves de los archivos de contenido van en inglés; los valores visibles, por idioma.
