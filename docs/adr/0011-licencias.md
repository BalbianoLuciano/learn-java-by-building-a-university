# ADR 0011 · Licencias

- **Estado:** aceptada
- **Fecha:** 2026-10-01

## Contexto

Proyecto open source con código y contenido educativo.

## Decisión

Código bajo **MIT**. Contenido (`content/`, `docs/`) bajo **CC BY-SA 4.0**.

## Consecuencias

- Cualquiera puede usar el código libremente.
- Quien reutilice las lecciones debe citar la fuente y compartir sus cambios con la misma licencia.
- Las fuentes de la UTN se citan; no se copia contenido del curso de la cátedra.
